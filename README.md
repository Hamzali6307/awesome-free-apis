# 🌐 Awesome Free Public APIs

A curated, categorized collection of **free public APIs** for developers — great for learning, side projects, hackathons, and prototyping. No scraping, no paywalls (unless noted), just APIs you can start calling today.

> ⭐ If this helped you, consider starring the repo and submitting a PR to add more APIs!

## Legend

| Symbol | Meaning |
|---|---|
| **Auth: No** | No authentication required |
| **Auth: apiKey** | Requires a free API key (sign up, no credit card) |
| **Auth: OAuth** | Requires OAuth registration |
| **HTTPS** | API is served over HTTPS |
| ⚠️ | Free tier has strict rate limits — check docs before production use |

> **Note:** Public APIs occasionally change endpoints, rate limits, or shut down. Before relying on one in production, check its docs/status page. Contributions to fix dead links are welcome.

## 🤝 Contributing

Contributions are welcome! To add an API:

1. Fork this repository.
2. Add your entry to the relevant category table (keep alphabetical order where possible).
3. Confirm the API is free (or has a genuinely usable free tier), has documentation, and the link works.
4. Open a pull request describing the addition.

Please avoid submitting APIs that are paid-only, require a business account, or have been discontinued.
